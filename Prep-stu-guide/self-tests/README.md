# نافذة الإختبارات الذاتيه — منصة معين (نسخة مستقلة)

نسخة مستقلة بالكامل من صفحة **«نافذة الإختبارات الذاتيه»** لمنصة معين التعليمية، مبنية كصفحة ويب ثابتة
(HTML + CSS + JavaScript) بدون أي اعتماد على خادم أو إطار عمل — جاهزة لل:

- **إختبار عملها وسلوكها** محلياً أو على أي استضافة ثابتة.
- **النشر على GitHub Pages** مباشرة.
- **الدمج لاحقاً** داخل حزمة مشروع «مكتبة أدوات معين» (مجلد واحد مستقل بملفاته).

> المصدر الأساسي للحقيقة هو مشروع Next.js الأصلي الذي أُنشئت منه هذه النسخة.
> عند تطوير قاعدة بيانات الإختبارات لاحقاً تُحدَّث النسخة المستقلة بإعادة توليد ملف البيانات أو نقل التعديلات.

---

## محتويات الحزمة

```
mueen-self-tests/
├── index.html                        ← الصفحة الرئيسية (نقطة الدخول)
├── README.md                         ← هذا الملف
└── assets/
    ├── favicon.svg                   ← شعار مُعين (أيقونة التبويب)
    ├── css/
    │   └── quiz-window.css           ← نظام التصميم الكامل (ألوان معين + ذهبي + RTL)
    ├── js/
    │   ├── icons.js                  ← أيقونات lucide + شعارات (مُعين/SEU/واتساب/تليجرام/X)
    │   ├── data.js                   ← بيانات المقررات + بنوك الأسئلة + الإختبارات الحقيقية + التجميعات
    │   └── app.js                    ← منطق الصفحة (التبويبات، البطاقات، أداء الإختبارات، المشاركة، الطباعه)
    └── compilations/
        └── academic-skills-compilation.pdf   ← ملف تجميعات المهارات الأكاديمية (21 صفحة)
```

## ما تتضمنه الصفحة

- الهوية البصرية الكاملة لمنصة معين (الهيدر، الهيرو، الفوتر، زر واتساب العائم).
- زر **«مشاركة الصفحة»** (واتساب / تليجرام / نسخ الرابط) وزر **«العودة للأدوات»**.
- بطاقات القروب والقناة، وزر المساعدة، وتبويبات **الخطة A / الخطة B**.
- بطاقات المقررات مع بطاقات الإختبارات الفرعية (بدء إختبار + أفضل نتيجة).
- **الإختبارات القصيرة الأربعة الأولى للمهارات الأكاديميه** بأسئلتها الرسمية الحقيقية (81 سؤالاً)
  مع مؤقت زمني متغير حسب عدد الأسئلة، ونتائج، ومراجعة تفصيلية للإجابات.
- **بطاقة تجميعات لكل مقرر**: أسماء الإختبارات + زر طباعه/تنزيل ملف التجميعات (متوفر حالياً للمهارات الأكاديميه، والبقية «قيد الإعداد» بانتظار ملفاتها خلال بناء قاعدة بيانات الإختبارات).
- **حفظ النتائج محلياً** في متصفح المستخدم (localStorage) — بديل قاعدة البيانات في النسخة الأصلية.

## إختبار النسخة محلياً

**الطريقة الأسرع:** افتح `index.html` مباشرة بالنقر المزدوج في المتصفح (يعمل بدون خادم).

**أو عبر خادم محلي** (الأقرب لسلوك GitHub Pages):

```bash
cd mueen-self-tests
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## النشر على GitHub Pages

### الطريقة الأولى: مستودع مستقل (لاختبار النسخة)

1. أنشئ مستودعاً جديداً على GitHub (مثال: `mueen-self-tests`).
2. ارفع محتويات مجلد `mueen-self-tests` (الملفات كما هي، وليس المجلد نفسه) إلى الفرع الرئيسي.
3. من إعدادات المستودع: **Settings → Pages → Build and deployment → Source: Deploy from a branch**،
   واختر الفرع الرئيسي (`main` / root).
4. بعد دقيقة تقريباً تصبح الصفحة متاحة على:
   `https://<username>.github.io/mueen-self-tests/`

> المسارات داخل الصفحة كلها نسبية (`assets/...`) لذلك تعمل تحت أي مسار فرعي دون أي تعديل.

### الطريقة الثانية: ضمن موقع مكتبة الأدوات

انسخ مجلد `mueen-self-tests` كاملاً داخل مستودع المكتبة، مثلاً:

```
<مستودع المكتبة>/
├── index.html                    ← صفحة مكتبة الأدوات الرئيسية
└── mueen-self-tests/             ← هذه الحزمة كما هي
    ├── index.html
    └── assets/...
```

ثم أضف من صفحة المكتبة رابطاً إليه:
`<a href="./mueen-self-tests/">نافذة الإختبارات الذاتيه</a>`

### ضبط زر «العودة للأدوات»

افتح `assets/js/app.js` وعدّل قيمة `TOOLS_URL` في كتلة `CONFIG` أعلى الملف:

```js
var CONFIG = {
  TOOLS_URL: '#',   // ← ضع هنا رابط صفحة مكتبة أدوات معين
  ...
}
```

أمثلة: `'/'` أو `'../index.html'` أو `'https://<username>.github.io/mueen-tools/'`.

## حفظ النتائج في هذه النسخة

تُحفظ أفضل النتائج وعدد المحاولات في **localStorage** للمتصفح تحت المفتاح
`mueen-self-tests-stats-v1` — كل مستخدم يرى نتائجه على جهازه فقط.

- حذف النتائج: امسح بيانات الموقع من المتصفح أو نفّذ في وحدة التحكم:
  `localStorage.removeItem('mueen-self-tests-stats-v1')`
- عند الدمج مستقبلاً داخل نسخة خادمية يمكن ربط الحفظ بواجهة API كما في المشروع الأصلي.

## إضافة مقررات/اختبارات جديدة مستقبلاً (بناء قاعدة بيانات الإختبارات)

كل البيانات في ملف واحد: **`assets/js/data.js`** ببنية `window.MUEEN_DATA`:

| القسم | الوظيفة |
|---|---|
| `plans.A` / `plans.B` | قوائم المقررات (الاسم، الوصف، بادئة الإختبار، عدد الإختبارات) |
| `banks` | بنك أسئلة احتياطي لكل مقرر (يُستخدم حين لا يتوفر ملف رسمي) |
| `realQuizzes` | أسئلة الإختبارات **الرسمية** مستخرجة من ملفات PDF (المفتاح: `A-academic-1` مثلاً) |
| `compilations` | حالة ملف التجميعات لكل مقرر (متوفر/قيد الإعداد + المسار + عدد الصفحات) |

**عند توفر ملفات مقرر جديد:**

1. ضع ملف التجميعات في `assets/compilations/`.
2. في `data.js` عدّل مدخل المقرر في `compilations`:
   اجعل `available: true`، وحدد `file` (المسار النسبي)، و`fileName`، و`includedIndexes`، و`pages`.
3. أضف أسئلة الإختبارات الرسمية في `realQuizzes` بنمط نفس المفاتيح
   (`"<الخطة>-<مفتاح-المقرر>-<رقم-الإختبار>"`) — كل سؤال:
   `{ question, options: [...], correctIndex, explanation }`.
4. عند إضافة مقرر جديد كلياً: أضفه في `plans` + مدخلاً فارغاً في `banks` و`compilations`.

تُفعَّل البطاقات تلقائياً: زر الطباعه يظهر، وشريحة «الملف الأصلي» تُعلَّم على الإختبارات الرسمية،
وتُحسب المدة تلقائياً (30 ثانية لكل سؤال رسمي بحد أدنى 5 دقائق).

## ملاحظات فنية

- الصفحة **RTL** بالكامل بخط Cairo (يُحمَّل من Google Fonts عند توفر الإنترنت، وبدونه يتراجع الخط تلقائياً إلى Tahoma/Arial).
- التصميم متجاوب: من 360px حتى الشاشات الكبيرة، وأهداف اللمس ≥ 44px.
- زر الطباعه يحمّل PDF في إطار مخفي ويستدعي الطباعه مباشرة، مع بديل تلقائي (فتح الملف في تبويب جديد) عند تعذر ذلك.
- لا يوجد أي اعتماد على حزم خارجية أو CDN سوى خط Cairo — كل الأيقونات والشعارات SVG داخلية.
